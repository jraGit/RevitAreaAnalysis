# Test data

Commit only sanitized, non-confidential test fixtures in this folder.

The supplied `dataRaw.workingV1.json` file was used locally for migration regression testing but is intentionally not copied into this deployable project. Select it through the browser file picker when testing locally.

Before publishing an example JSON, remove project names, addresses, client information, model identifiers, fingerprints, unique IDs, and any geometry or metadata that should remain private.
